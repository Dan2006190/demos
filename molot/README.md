# ЦВСП «Молот» — Гражданская медицина

Сайт-курс первой помощи по материалам канала клуба. Статический: без сервера и базы, работает на GitHub Pages и любом хостинге.

## Что внутри

- `index.html` — главная: первые минуты, модули курса, занятия клуба, правовая основа, контакты.
- `module.html?m=…` — страница модуля. Модули: `bleeding`, `fracture`, `amputation`, `burns`, `eye`, `head`, `cpr`, `kit`.
- `js/content.js` — **все тексты**. Править только его.
- `js/app.js` — сборка страниц и интерактив: рентген-линза с видами переломов, сосуды, жгут по шагам, слои ожога, тренажёр ритма СЛР.
- `css/style.css`, `fonts/` (шрифты лежат локально), `img/` (снимки без ФИО и дат).

## Как поменять текст

Откройте `js/content.js`, найдите нужный модуль и поправьте строки в кавычках. Теги `<b>…</b>` делают текст жирным.
Контакты — в самом верху: `vk`, `phone`.
Настоящие снимки в карусели переломов убираются строкой `window.REAL_XRAY = [];`.

## Перед публикацией — проверить инструктору

1. **Время наложения жгута.** В канале: «60 минут летом и зимой». Во многих методичках зимой — 30 минут. Сверить с Приказом Минздрава № 220н.
2. Все алгоритмы модулей: кровотечения, переломы, ампутация, ожоги, глаза, СЛР.
3. Раздел «Травма головы» пустой — нужен текст.
4. Ссылки на видео ведут в канал: `t.me/cvspmolot/8`, `/11`, `/35`.

## Как выложить на GitHub Pages (бесплатно)

1. Создать **публичный** репозиторий на GitHub, например `molot`.
2. Загрузить в него содержимое этой папки (Add file → Upload files).
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через минуту сайт будет по адресу `https://<логин>.github.io/molot/`.

Свой домен (`.ru`, около 300 ₽ в год) подключается там же, в Settings → Pages → Custom domain.

## Проверить у себя

Откройте папку в терминале и запустите `python -m http.server 8000`, затем откройте `http://localhost:8000`.
