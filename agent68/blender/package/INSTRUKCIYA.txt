АГЕНТ 68 — РЕНДЕР В КЛУБЕ. Инструкция на одну страницу

ПК клуба: Ryzen 7 7700, RTX 4070 Super (12 ГБ), 32 ГБ памяти — подходит с запасом.
Нужно: Windows 10/11, интернет на первый запуск, 6 ГБ свободного места на диске D: (или любом другом).

1. СКАЧАТЬ И РАСПАКОВАТЬ
   Скачайте agent68.zip по присланной ссылке (~35 МБ).
   Правой кнопкой по zip → Свойства → внизу галочка «Разблокировать» → ОК.
   Правой кнопкой по zip → «Извлечь всё…» → укажите D:\ → Извлечь. Получится папка D:\agent68.

2. ПРОБА — TEST.bat (10–20 минут)
   Двойной щелчок по TEST.bat из папки D:\agent68 (не изнутри zip).
   Если Windows пишет «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
   Первый раз программа сама скачает Blender 4.5 LTS (portable, ~400 МБ) и фактуры Poly Haven (~200 МБ).
   Затем считает по 2 кадра каждого вида и пишет прогноз: «ВСЕГО ≈ … ч».
   Прогноз — в окне и в файле D:\agent68\renders\obj1\status.txt (открывается Блокнотом).
   Сфотографируйте прогноз и пришлите.

3. РЕНДЕР — START.bat (ожидается 1–2 часа, точно — по прогнозу)
   Двойной щелчок по START.bat. Окно не закрывать, в игры не играть. Монитор можно выключить —
   компьютер сам не уснёт, пока идёт работа.
   Порядок: облёт (144 кадра) → подлёт (84) → главные кадры (3) → маска этажа (144) → manifest.json.
   Ход работы — renders\obj1\status.txt.

4. ОТПРАВИТЬ
   Двойной щелчок по pack.bat → появится agent68_renders_ДАТА.zip, папка с ним откроется сама.
   Пришлите zip (Telegram, Яндекс Диск — как удобно).

ЕСЛИ ПРЕРВАЛОСЬ
   Ничего не потеряно: готовые кадры сохранены. Снова START.bat — продолжит с того же места.

ЕСЛИ ЧТО-ТО НЕ ТАК
   • Окно пишет красным и стоит — сфотографируйте окно и пришлите вместе с файлом D:\agent68\log.txt.
   • «Драйвер устарел» — обновите драйвер с nvidia.com (Драйверы → GeForce), перезагрузите, снова START.bat.

Спасибо!
