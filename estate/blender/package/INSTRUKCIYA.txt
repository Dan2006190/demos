АРДЕН — РЕНДЕР НА НОЧЬ. Инструкция на одну страницу

Нужно: Windows 10/11, видеокарта NVIDIA (у вас RTX 3080), 16 ГБ оперативной памяти или больше,
интернет на первый запуск, 40 ГБ свободного места на диске D: (или любом другом).

1. СКАЧАТЬ
   Скачайте файл arden-v2.zip по ссылке, которую вам прислали (~70 МБ).
   Нажмите на zip правой кнопкой → Свойства → внизу поставьте галочку «Разблокировать» → ОК.

2. РАСПАКОВАТЬ
   Правой кнопкой по zip → «Извлечь всё…» → укажите D:\  → Извлечь.
   Должна получиться папка D:\arden (в ней START.bat, pack.bat и этот файл).

3. ЗАПУСТИТЬ — вечером
   Двойной щелчок по START.bat — из папки D:\arden, а не изнутри zip (из zip программа не запустится).
   Если Windows пишет «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
   Первый раз программа сама скачает Blender и модели (~1,3 ГБ, 10–30 минут), потом начнёт рендер.
   Окно не закрывать. Компьютер не выключать и в игры не играть. Монитор можно выключить —
   компьютер сам не уснёт, пока идёт работа.
   Что сделано и сколько осталось — в файле D:\arden\renders\status.txt (открывается Блокнотом),
   строка «Всего осталось ≈ … ч (готово примерно к …)».

4. УТРОМ
   Если окно ещё работает — просто закройте его (крестиком). Ничего не потеряется:
   готовые кадры сохранены, в следующий раз START.bat продолжит с того же места.
   Двойной щелчок по pack.bat → появится файл arden_renders_ДАТА.zip, папка с ним откроется сама.
   Пришлите этот zip (Telegram, Яндекс Диск, Google Диск — как удобно).

5. ЕСЛИ НЕ ЗАКОНЧИЛОСЬ ЗА НОЧЬ
   Это нормально: всё займёт около 9–15 часов, то есть 1–2 ночи. Следующей ночью снова START.bat, утром снова pack.bat.

ЕСЛИ ЧТО-ТО НЕ ТАК
   • Окно пишет красным и стоит — сфотографируйте окно и пришлите вместе с файлом D:\arden\log.txt.
   • «Драйвер устарел» — обновите драйвер с nvidia.com (Драйверы → GeForce), перезагрузите, START.bat.
   • «Мало места» — освободите диск или перенесите папку arden на другой диск целиком.
   • Если коротко (часа 3) — START_3h.bat: быстрее, чуть больше шума на картинке.

Спасибо!
