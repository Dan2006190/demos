АРДЕН — РЕНДЕР НА НОЧЬ. Инструкция на одну страницу

Нужно: Windows 10/11, видеокарта NVIDIA (у вас RTX 3080), 16 ГБ оперативной памяти,
интернет на первый запуск, 40 ГБ свободного места на диске.

1. BLENDER (один раз)
   Скачайте Blender 4.5 LTS с blender.org (Download → Windows Installer) и установите
   как обычную программу: Далее → Далее → Готово. Если забудете — START.bat сам откроет эту страницу.

2. РАСПАКОВАТЬ
   Правой кнопкой по arden-v2.zip → «Извлечь всё…» → Извлечь.
   Получится папка arden (в ней START.bat, pack.bat и этот файл). Запускать только оттуда, не изнутри zip.

3. ЗАПУСТИТЬ — вечером
   Двойной щелчок по START.bat. Если Windows пишет «Windows защитила ваш компьютер» →
   «Подробнее» → «Выполнить в любом случае».
   Первый раз скрипт докачает модели травы и деревьев (~800 МБ, 5–20 минут), потом начнёт рендер.
   Окно не закрывать, в игры не играть. Монитор можно выключить — компьютер сам не уснёт.
   Сколько сделано и сколько осталось — в файле arden\renders\status.txt (открывается Блокнотом).

4. УТРОМ
   Если окно ещё работает — просто закройте его крестиком. Ничего не потеряется:
   следующий запуск START.bat продолжит с того же места.
   Двойной щелчок по pack.bat → появится arden_renders.zip, папка с ним откроется сама.
   Пришлите этот файл (Telegram, Яндекс Диск — как удобно).

5. ЕСЛИ НЕ ЗАКОНЧИЛОСЬ ЗА НОЧЬ
   Это нормально: всё займёт около 9–15 часов, то есть 1–2 ночи. Следующей ночью снова START.bat.

ЕСЛИ ЧТО-ТО НЕ ТАК
   • Окно остановилось с ошибкой — сфотографируйте его и пришлите вместе с файлом arden\log.txt.
   • Если коротко (часа 3) — START_3h.bat: быстрее, чуть больше шума на картинке.

Спасибо!
