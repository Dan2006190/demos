# Рендер Ардена v2 — кадры для сайта «псевдо-3D»

v2 перестраивает сцену сайта целиком, без плоских заплаток: газон из сканированной травы Poly Haven
(инстансы через Geometry Nodes, отсечение по кадру и расстоянию), кусты, цветы, клевер (кислица), одуванчики,
заборы и ворота геометрией (профлист, евроштакетник, дерево), дорога с рельефом, заплатками, стёртой
разметкой, бордюром, люками; мощение, клумбы и земля — с рельефом (адаптивное подразделение Cycles);
машины у ворот, мебель и кадки, беседки и качели; ближний лес — ели Poly Haven. Картинка — закат,
свечение, лёгкая виньетка и цветокоррекция. Окна — тонкое стекло без преломления.

## Файлы

| Файл | Что делает |
|---|---|
| `arden_render.py` | рендер по приоритетам: облёт посёлка → облёты домов → подлёты → вступление; `status.txt`; откат при нехватке видеопамяти |
| `arden_v2.py` | сборка сцены v2 поверх выгрузки сайта |
| `arden_assets.py` | список и загрузчик ассетов Poly Haven (модели 1K, фактуры 2K с картой высот) |
| `sectors.json` | чистые сектора облёта домов (сзади камера уходит в ёлки) — общие с `make_media.py` |
| `make_media.py` | рендер → облегчённые файлы сайта в `estate/media` (досчёт промежуточных кадров, размеры, видео) |
| `build_package.py` | собирает пакет `arden-v2.zip` для рендера на чужом ПК |
| `package/` | `START.bat`, `START_3h.bat`, `pack.bat`, `INSTRUKCIYA.txt` и `tools/*.ps1` — то, что видит человек |
| `export.js` | выгрузка сцены сайта (`?export=1&3d=1`, кнопка внизу слева) |

## Что рендерит (1920×1080, Cycles)

| Этап | Кадров | Сайт получает |
|---|---|---|
| 1. облёт посёлка, через 2,5° | 144 | 288 (досчитывается 1 кадр между соседними) |
| 2. облёты домов, чистые сектора через 7,5° | 172 | ×2 (досчитывается 1 кадр) |
| 3. подлёты, 3,5 с при 24 к/с | 6 × 84 | 6 роликов MP4 |
| 4. вступление сквозь облака, 8 с | 193 | `intro.mp4` (последний кадр = облёт, кадр 0) |

Траектории и нумерация — как в v1: manifest, сектора и стык с подлётом остаются валидными.
Качество: «ночь» (по умолчанию) — 96 выборок (облака 64), «3 часа» — 48 (облака 32); адаптивная
выборка, шумодав OptiX с альбедо и нормалями, до 6 отражений, без каустик, persistent data.

## Пакет для рендера на чужом ПК

```bash
python3 estate/blender/build_package.py ПАПКА_СЦЕНЫ arden-v2.zip
```

`ПАПКА_СЦЕНЫ` — выгрузка сайта (`village.glb`, `village.json`, `sky_2k.hdr`) и `assets/cars` (машины Sketchfab
с `info.json`). Пакет ~130 МБ; Blender 4.5 LTS (blender.org, с проверкой SHA-256) и ассеты Poly Haven (~800 МБ)
`START.bat` докачивает сам. Перед стартом проверяет видеокарту NVIDIA, драйвер (550+), видеопамять (8+ ГБ),
оперативную память (16+ ГБ) и место на диске (25+ ГБ), не даёт компьютеру уснуть, при падении Blender
перезапускает (готовые кадры не пересчитываются). При нехватке видеопамяти скрипт сам снижает нагрузку
по ступеням: трава 60 % и фактуры 1024 → трава 35 % и упрощённые ели → трава 20 % и фактуры 512 → процессор.

Инструкция для человека — `package/INSTRUKCIYA.txt`: скачать, распаковать в `D:\`, `START.bat`, утром `pack.bat`
и прислать `arden_renders_ДАТА.zip`.

## После рендера: файлы для сайта

Распакуйте присланный zip в `estate/renders` (в коммит не добавлять; оригиналы хранятся в ветке
`estate/renders`) и соберите облегчённые копии:

```bash
pip install pillow opencv-python-headless numpy
python3 estate/blender/make_media.py --force
```

## Проверка скрипта без видеокарты

```bash
blender -b -P estate/blender/arden_render.py -- --scene ПАПКА_СЦЕНЫ --out /tmp/r --what test --cpu --percent 50
```

Проверочный кадр с любой точки (координаты сайта: x, высота, z и точка, куда смотреть):

```bash
blender -b -P estate/blender/arden_render.py -- --scene ПАПКА_СЦЕНЫ --out /tmp/r --cpu --percent 50 --look=-17.5,1.6,-29.8,-40,1.4,-41
```
