Демо-сайт: Алессия (alessia_gloss), Тамбов

Одностраничный сайт мастера по кератину и мобильная админка для записи. Сделан сначала под телефон, потом под компьютер. Работает без сервера: файлы открываются прямо в браузере.

Файлы

  • `index.html` — Сайт: первый экран, услуги, диагностика, работы (до/после + карусель), онлайн-запись, вопросы, контакты
  • `admin.html` — Админка Алессии: календарь (занято/свободно), список заявок
  • `assets/style.css` — Общие стили, шрифты, календарь
  • `assets/store.js` — Демо-хранилище дат и заявок (localStorage браузера)
  • `assets/calendar.js` — Календарь на месяц, общий для сайта и админки
  • `materials/` — Фото из Instagram Алессии (используются напрямую)

Как показать демо с телефона

  • Открыть index.html → пролистать, потянуть ползунок «до/после», полистать карусель.
  • В блоке «Запись на 11:00» выбрать дату, процедуру, ввести имя и телефон → экран «Заявка отправлена Алессии в Telegram».
  • Внизу страницы «Вход для Алессии →» (или admin.html) → заявка в списке, дата занята. Там же можно занять/освободить день.
  • Если сайт и админка открыты в одном браузере, данные общие. «Сбросить демо-данные» внизу админки возвращает исходное состояние.
