# Демо-сайт: Алессия (alessia_gloss), Тамбов

Одностраничный сайт мастера по кератину и мобильная админка для записи. Сделан сначала под телефон, потом под компьютер. Работает без сервера: файлы открываются прямо в браузере.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Сайт: первый экран, услуги, диагностика, работы (до/после + карусель), онлайн-запись, вопросы, контакты |
| `admin.html` | Админка Алессии: календарь (занято/свободно), список заявок |
| `assets/style.css` | Общие стили, шрифты, календарь |
| `assets/store.js` | Демо-хранилище дат и заявок (localStorage браузера) |
| `assets/calendar.js` | Календарь на месяц, общий для сайта и админки |
| `materials/` | Фото из Instagram Алессии (используются напрямую) |

## Как показать демо с телефона

1. Открыть `index.html` → пролистать, потянуть ползунок «до/после», полистать карусель.
2. В блоке «Запись на 11:00» выбрать дату, процедуру, ввести имя и телефон → экран «Заявка отправлена Алессии в Telegram».
3. Внизу страницы «Вход для Алессии →» (или `admin.html`) → заявка в списке, дата занята. Там же можно занять/освободить день.
4. Если сайт и админка открыты в одном браузере, данные общие. «Сбросить демо-данные» внизу админки возвращает исходное состояние.

Чтобы открыть с телефона, папку нужно выложить на любой статический хостинг (например, GitHub Pages, Netlify), т. к. локальные файлы с компьютера на телефоне не откроются.

## Что взято из профиля, а что — пример

**Из материалов задачи:** имя, ник, город, «правила задаю я», «0% сказок для «убитого» блонда», «100% научная диагностика», «зеркальный глянец, который выглядит дорого», тест на эластичность, один клиент в день на 11:00, три услуги.

**Помечено «пример» / требует согласования:**
- цены «от …» и сроки носки у всех трёх процедур;
- описания процедур, описание теста на эластичность (3 шага), ответы в FAQ;
- подписи процедур под фото в карусели;
- адрес «ул. Октябрьская, 47» (помечен «уточняется»);
- ссылка на Telegram (сейчас заглушка);
- карта (заглушка → Яндекс.Карты).

Отзывы, стаж, количество клиентов и награды на сайте не указаны: их нет в материалах.
